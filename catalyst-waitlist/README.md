# Catalyst Waitlist

Плагин Soft Hub для формы **Join waitlist** на [catalyst.app](https://catalyst.app/).

Заявка — один JSON-запрос `POST https://api.catalyst.app/api/v1/auth/waitlist` через proxy аккаунта. Тело такое же, как у формы: `email`, необязательный `twitterHandle` и `referralCode` прямого родителя.

## Перед запуском

1. У каждого аккаунта заполнены email и HTTP-proxy. Поле Twitter аккаунта софту не нужно, пустое не мешает запуску.
2. Публичный handle, если он нужен, кладётся в **Данные софтов** этого софта, ключ `twitter_handle`, значение `name` или `@name`. Без ключа заявка уходит только с email. Логин:пароль и токен софт не отправляет.
3. В **Настроить цепочку** родитель стоит над ребёнком. Циклы Hub не сохранит.
4. В один запуск берёте всю ветку: корень и его детей. Ребёнок без родителя в этом же запуске не отправляется.

## Как идёт цепь

Уровни идут сверху вниз. Внутри уровня аккаунты работают параллельно, число задаёт **Параллельные аккаунты**. Следующий уровень начинается, когда родители этого запуска получили invite-ссылку.

Корень уходит без кода. Ребёнок получает только код своего прямого родителя из ответа этого запуска. Код не пишется в журнал, таблицу и summary.

Если родитель уже был в списке, а API не вернул ссылку повторно, дети этого запуска остановятся. Повторять такую заявку вслепую не нужно: сначала проверьте почту на сайте.

## Установка

Соберите пакет и перетащите его в **Патчи**:

```bash
python3 scripts/build_plugin.py catalyst-waitlist dist/catalyst-waitlist-1.0.2.softhub.zip
```

Нужен Soft Hub `0.6.29` или новее. Раздел карточки — **NFT** (туда Hub складывает WL). Риск действия — внешняя запись, не транзакция.
