# Catalyst Waitlist

Патч Soft Hub для формы Join waitlist на [catalyst.app](https://catalyst.app).

## Установка

```text
dist/catalyst-waitlist-1.0.2.softhub.zip
```

Soft Hub → Патчи, либо Patch Radar: репозиторий `catalyst-waitlist.patch`, релиз `v1.0.2`.

## Сборка

```bash
python3 scripts/build_plugin.py \
  catalyst-waitlist \
  dist/catalyst-waitlist-1.0.2.softhub.zip
```
